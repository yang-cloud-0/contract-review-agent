# 租房合同风险审查 Agent（contract-review-agent）

[English → README.en.md](README.en.md)

上传一份租房合同，自动定位押金不退、任意涨租、维修责任转嫁等风险条款，
给出对应的法规条文引用和修改建议。

> **状态：项目刚启动，本文是实现路线图，不是完成说明。**
> 这是继 [MewCode Lite](https://github.com/yang-cloud-0/mewcode) 之后的第二个学习项目，
> 按下面的最小范围逐步实现，每完成一步才更新这里的“已完成”清单。

## 最小版范围（v0.1 目标）

只做一条主链，先跑通再加东西：

1. **解析**：读取合同文本（先支持 .txt / 粘贴文本），按条款切分
2. **检索**：用 BM25 在一个小型法规知识库（民法典租赁相关条文，人工整理成条文粒度）
   里为每个可疑条款找依据
3. **审查**：LangGraph 编排 3 个节点（解析 → 检索 → 审查报告），
   模型输出风险点 + 引用的法条原文
4. **引用校验**：程序逐字核对模型引用的法条原文是否真的存在于检索结果中，
   对不上就标红/剔除——这是本项目最重要的一步，防模型编法条
5. **评测**：先用 5 份人工标注的样本统计风险召回与误报，不吹大数字

## 明确不做（第一版）

- 向量检索 / RRF 融合 / 重排（BM25 跑通、评测有了 baseline 之后再加，用数据决定要不要）
- interrupt + checkpointer 人工确认断点（第二版，理解 LangGraph 基础编排之后再上）
- PDF/Word 复杂版式解析、Web 界面

## 技术栈

Python · LangGraph · BM25（先手写或用 rank_bm25，届时在提交里说明选择理由）· pytest
